## Number Guessing Game (Python)

A simple Python game where the computer selects a random number between 1 and 10, and the player tries to guess it.

### Features
- Random number generation
- Unlimited guessing attempts
- Hints: Too low or Too high
- Play again option
- Beginner-friendly Python project

### How to Run

1. Install Python.
2. Download `number_guessing_game.py`.
3. Open the terminal in the file's folder.
4. Run this command:

```bash
python number_guessing_game.py
```

### Concepts Used
- Variables
- Input and output
- If-elif-else conditions
- While loops
- Random module
- Break statement
